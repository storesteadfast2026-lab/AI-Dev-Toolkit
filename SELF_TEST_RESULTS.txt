DESIGN DECISION
---------------
Python/PySide/QProcess child execution has been removed completely.
The full GUI itself now runs in Windows PowerShell 5.1 / Windows Forms.

The child-process engine uses the same design manually proven on the target Windows PC:
PowerShell GUI -> .NET ProcessStartInfo -> cmd.exe -> CMD wrapper -> BAT -> .log.
